# NeuroScan AI – Brain Tumor Classification Using Deep Learning

## Overview
NeuroScan AI is a deep learning project that classifies brain tumors from MRI images using Convolutional Neural Networks (CNNs).

The project focuses on building an AI pipeline including data preprocessing, model training, evaluation, and Explainable AI analysis.

## Features
- MRI image classification
- Deep learning pipeline development
- Image preprocessing and augmentation
- Model training and validation
- Explainable AI using Grad-CAM

## Models Used
- ResNet50
- EfficientNet-B7

## Technologies
- Python
- TensorFlow
- Keras
- Deep Learning
- CNN
- Grad-CAM
- Google Colab

## Project Workflow

1. Data Preparation
2. Image Preprocessing
3. Model Training
4. Model Evaluation
5. Explainability Analysis

## Evaluation Metrics

- Accuracy
- Precision
- Recall
